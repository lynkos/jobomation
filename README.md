## Requirements
- [x] OpenCode
- [x] Node.js

## Installation
1. Install OpenCode
  ```sh
  brew install anomalyco/tap/opencode
  ```

2. Install dependencies
   ```sh
   npm install
   npm run setup-browser
   npm run build
   ```
